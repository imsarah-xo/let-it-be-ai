# Let It Be AI

## AI-Powered Image Transformation Web Application

Let It Be AI is an AI-powered web application designed to provide users with a collection of intelligent image transformation tools through a simple and user-friendly interface.

### Features

- Image Restoration
- Background Removal
- Object Removal
- Object Recoloring
- Generative Fill
- User Authentication
- Credit-based image processing
- Payment integration

### Technologies Used

- Next.js
- TypeScript
- MongoDB
- Cloudinary AI
- NextAuth
- Razorpay

### Project Overview

The application provides an integrated platform where users can upload images and apply different AI-powered transformations. It also includes user authentication and a credit-based system for managing image processing operations.
